Design system — components

Phase 2 of the design system: plain-CSS components built on the token layer. No framework, no build step — copy theme/tokens.css and theme/ncdpi-ds.css into a project and use the classes. Every color pairing below references semantic tokens only and is contrast-validated on every build (the grid); each component ships with when-to-use notes and an accessibility definition of done.

NoteWhere the shapes come from

Component anatomy and accessibility contracts follow the government-grade exemplar systems (USWDS, GOV.UK). The skin is ours: First in Flight + warm professionalism. dpi.nc.gov was audited for kinship, not copied — its components are theme defaults, not documented decisions. One deliberate divergence: the live site’s buttons are full pills; ours keep the system’s subtle 6px radius. One deliberate adoption: the card’s navy top bar, the live site’s most distinctive house shape.

Button — .ncdpi-btn

Three variants, in descending visual weight. Works on <button> and <a>.

<button class="ncdpi-btn ncdpi-btn--primary">Download the data</button>
<button class="ncdpi-btn ncdpi-btn--secondary">See the methodology</button>
<button class="ncdpi-btn ncdpi-btn--quiet">Cancel</button>

When to use. One primary button per view — the single action you most want taken. Secondary for the alternatives worth a border; quiet for low-stakes actions (cancel, dismiss) that shouldn’t compete. If it navigates, it’s an <a>; if it does something on the page, it’s a <button> — style is not semantics.

Definition of done. Focus-visible ring (3px focus token, 2px offset) · white-on-navy and white-on-hover-blue both validated 4.5:1 · disabled state uses the WCAG disabled exemption knowingly · motion respects prefers-reduced-motion · never a <div onclick>.

Callout — .ncdpi-callout

Info (default), danger, neutral. The title’s word carries the meaning; color reinforces it but never carries it alone.

Note Graduation-rate data for 2025–26 is embargoed until September 2. Charts on this page show the prior cohort.
Important This file contains student-level identifiers. Do not upload it — use the de-identified extract instead.
Background District values are unweighted means of school rates — demonstration data, not official statistics. 
<div class="ncdpi-callout ncdpi-callout--danger">
  <strong class="ncdpi-callout__title">Important</strong>
  This file contains student-level identifiers. Do not upload it.
</div>

When to use. Info for asides the reader can skip; danger for consequences (data loss, PII, compliance) — and only consequences, because red is the alert channel, never decoration (that’s DIT’s own live practice); neutral for background that shouldn’t tint the page blue. Don’t put links in a neutral callout — the link blue is deliberately not claimed on the sunken fill.

Definition of done. Title word names the severity · body ink is near-black on every tint (both pairings machine-validated) · role="alert" only when injected dynamically — static callouts need no role · left border is ≥3:1 against the fill or purely decorative reinforcement.

Card — .ncdpi-card

The workhorse container. --accent-top adds the navy top bar — the kinship cue adopted from dpi.nc.gov’s CTA cards.

Token reference

Updated August 2026

Every color, type, space, and radius token, with the contrast guarantees each one makes.

Plain card

No top bar, shadow at rest. Use for content that sits beside an accented sibling.

Flat card

Border only. Use inside dense layouts where stacked shadows get noisy.

<div class="ncdpi-card ncdpi-card--accent-top">
  <h3 class="ncdpi-card__title"><a href="…">Token reference</a></h3>
  <p class="ncdpi-card__meta">Updated August 2026</p>
  <p>Every color, type, space, and radius token…</p>
</div>

When to use. Grouping one self-contained thing — a link target, a summary, a download. Not for laying out whole pages (that’s spacing’s job), and not nested inside another card. Linked cards: the title is the link. Whole-card click targets break text selection and flood screen-reader link lists; the focus ring on the card (via :has()) keeps the affordance visible.

Definition of done. Heading level fits the page outline (the class styles any of h2–h4) · title link keyboard-reachable with a visible ring · card never traps focus · reads correctly with CSS off (it’s just a heading and paragraphs).

Badge — .ncdpi-badge

Compact status labels. Neutral (default), info, accent, outline.

Draft 2024–25 cohort Embargoed 115 districts 
<span class="ncdpi-badge ncdpi-badge--info">2024–25 cohort</span>
<span class="ncdpi-badge ncdpi-badge--accent">Embargoed</span>

When to use. One or two words of status or count, next to the thing they describe. Accent is the alert-family red — reserve it for states a reader must not miss (embargoed, action required), never for decoration. A badge is text, not a control: if it’s clickable, it’s a button or link wearing the wrong class.

Definition of done. Every variant ≥4.5:1 despite the 14px size (held to normal-text AA, not the large-text discount) · never the only carrier of the status (the row’s text or an aria-label says it too) · not focusable.

Stat tile — .ncdpi-stat

The BAN component — and the design system’s D2 boundary worked example. The ruling (PLAN.md, session 32): a stat tile is UI chrome with a chart-world number. It renders in Source Sans, because it lives in the page and is never exported — but its data semantics follow chart conventions: valence colors come from the dataviz palettes (via the read-only --ncdpi-chart-* mirror, never First in Flight), and it carries a C7-style source line. A BAN that must be exported to PowerPoint or print is chart-creator’s matplotlib BAN — sibling, not rival.

4-year cohort graduation rate 86.4% ▲ up 1.2 pts from 2024 Source: NC School Report Cards, 2025. Demonstration data.
Chronic absenteeism 24.1% ▲ up 0.8 pts from 2024 Source: NCDPI attendance files, 2025. Demonstration data.
Districts reporting 115 all LEAs, no change Source: NCDPI LEA directory, 2025. 
<div class="ncdpi-stat">
  <span class="ncdpi-stat__label">4-year cohort graduation rate</span>
  <span class="ncdpi-stat__value">86.4%</span>
  <span class="ncdpi-stat__delta ncdpi-stat__delta--good">▲ up 1.2 pts from 2024</span>
  <span class="ncdpi-stat__source">Source: NC School Report Cards, 2025.</span>
</div>

When to use. The number is the message (BAN rules apply — see the KPI page): label first so the number has a question to answer, one decimal at most, delta gives the number its “compared to what.” Note the middle tile: absenteeism went up, which is bad — valence follows meaning, not direction. That’s why the class is --good/--bad, not up/down.

Definition of done. Direction stated in words or sign, never color alone (the ▲ is decoration; “up … from 2024” is the content) · valence colors verified 4.5:1 on both tile surfaces · source line present (C7) · label, value, delta, source read in that order in the DOM.

Header & footer — .ncdpi-header / .ncdpi-footer

The brand band. The logo drops into the brand slot as an <img> — use a white/reversed mark on the navy; the logo page covers which file, sizing, and alt text. The component only reserves the slot.

NC Department of Public Instruction Educator Preparation Data
Questions? Contact the data team · Data current as of August 2026 
<header class="ncdpi-header">
  <span class="ncdpi-header__brand"><img src="…white logo…" alt="NC DPI">
    NC Department of Public Instruction</span>
  <span class="ncdpi-header__tagline">Educator Preparation Data</span>
</header>

When to use. Standalone HTML pages, dashboards, and apps that need to say whose they are — the style-guide site itself keeps Quarto’s navbar. Links inside the bands are white and underlined: the navy band is the one place link blue can’t go.

Definition of done. <header>/<footer> landmarks, not divs · white on navy validated (on-surface-brand) · logo <img> carries alt text · tagline dim measured 11.1:1 (AAA headroom).

Data table — .ncdpi-table

UI-chrome tables, on the tokens.

Graduation rate by SBE region, 2025
Region Districts Rate
North Central 17 84.8%
Piedmont Triad 16 87.1%
Sandhills 14 80.0%
Southwest 12 88.3%
State 115 86.4%

Demonstration data — unweighted means, not official statistics.

<table class="ncdpi-table">
  <caption>Graduation rate by SBE region, 2025</caption>
  <thead><tr><th scope="col">Region</th><th scope="col" class="num">Rate</th></tr></thead>
  <tbody><tr><th scope="row">Sandhills</th><td class="num">80.0%</td></tr></tbody>
</table>

When to use. Pages and apps — admin lists, roster views, dashboard detail. D2 boundary, same ruling as the stat tile: a table that accompanies a chart (the companion data table of the accessibility guidance) is a chart-world artifact and keeps the dataviz styling on the table elements page; this component is for UI. Anatomy is non-negotiable: <caption> always, scope on every header cell, .num right-aligns with tabular figures.

Definition of done. Caption present · th[scope] on columns and rows · zebra stripes are the sunken token (body text validated on it) · numeric columns aligned on tabular figures · no layout tables, ever.

Tabs — .ncdpi-tabs

The one component that ships behavior: theme/ncdpi-ds.js (optional third file, vanilla, ~100 lines) wires the WAI-ARIA tabs pattern. Without JS the panels simply stack — degraded, never broken.

115 local education agencies, matched by name, code, or official name.

100 counties, matched by name, DPI code (1–100), or FIPS.

8 State Board of Education regions, matched by name or number.

<div class="ncdpi-tabs" data-ncdpi-tabs>
  <div class="ncdpi-tabs__list" aria-label="Geography">
    <button class="ncdpi-tabs__tab" data-panel="tab-districts">Districts</button>
    …
  </div>
  <div class="ncdpi-tabs__panel" id="tab-districts">…</div>
</div>
<script src="theme/ncdpi-ds.js"></script>

When to use. Alternate views of the same thing (geographies of one dataset, code/preview of one example). Not for sequential steps (that’s a wizard) and not for unrelated content (those are pages). If users need to compare two panels side by side, tabs are the wrong pattern.

Definition of done. Arrow/Home/End keys move selection (roving tabindex) · roles and aria-selected set by the JS, never claimed in static markup · panel focusable · selected state marked by more than color (the 3px underline + text-color shift).

Breadcrumb — .ncdpi-breadcrumb

  1. Home
  2. Design system
  3. Components
<nav class="ncdpi-breadcrumb" aria-label="Breadcrumb">
  <ol>
    <li><a href="/">Home</a></li>
    <li><a href="/data/">Data & Reports</a></li>
    <li aria-current="page">Graduation rates</li>
  </ol>
</nav>

When to use. Three or more levels of real hierarchy. The current page is plain text with aria-current="page", never a link; the › separator is CSS-generated so screen readers don’t read it as content.

Definition of done. <nav aria-label="Breadcrumb"> + <ol> · separator out of the accessibility tree · current page not focusable.

Skip link — .ncdpi-skip-link

Promoted from the style-guide site (it’s been live since session 20 — WCAG 2.4.1). First focusable element on the page, hidden until focused.

Skip to main content

Click into this frame and press Tab — the link drops in from the top edge.

<body>
  <a href="#main" class="ncdpi-skip-link">Skip to main content</a>
  <header class="ncdpi-header">…</header>
  <main id="main">…</main>

When to use. Every page with repeated navigation before the content — which is every page. Point it at the <main> element’s id.

Definition of done. First element in the DOM · visible on focus with the ring · target id exists (a dead skip link is worse than none).

Chart frame — .ncdpi-chartframe

The C2/C7 wrapper for charts embedded in pages and apps — and the D2 boundary’s other worked example: everything in this frame is chart-world text (Arial, chart-text colors, the dataviz guide’s pt sizes), because the frame belongs to the chart, not the page.

<figure class="ncdpi-chartframe">
  <div class="ncdpi-chartframe__title">Message title, not a topic label</div>
  <div class="ncdpi-chartframe__subtitle">Measure, population, year — the contract</div>
  <div class="ncdpi-chartframe__body"><!-- the chart --></div>
  <div class="ncdpi-chartframe__source">Source: …</div>
</figure>

When to use. Any chart dropped into an app or HTML page (the map-maker retrofit is the intended first consumer). Title states the message; subtitle is the contract (measure, population, year); source line always (C7); all four share the left edge (C2). On the style-guide site itself, chart-loader.js already renders this structure for Vega specs — this class packages the same anatomy for everything else.

Definition of done. All text Arial at the chart sizes (14pt title, 11pt subtitle/source as px) · shared left edge, no centered titles · source line present · the chart body carries its own alt text (role="img" + label, or a companion table).

Form basics — .ncdpi-field

Deliberately minimal (label + control + help + error). Form-heavy coverage is out of scope until adoption demands it.

The value the darkest map color should represent — often 100.

Error: enter a year between 2015 and 2026.

<div class="ncdpi-field ncdpi-field--error">
  <label class="ncdpi-field__label" for="year">Reporting year</label>
  <input class="ncdpi-input" id="year" aria-describedby="year-error" aria-invalid="true">
  <p class="ncdpi-field__error" id="year-error">Error: enter a year between 2015 and 2026.</p>
</div>

When to use. The occasional input a data product needs (a goal value, a filter, an email field) — not full multi-step forms. Error messages name the problem and the fix, in words (“Error: enter a year between 2015 and 2026”), never just a red border.

Definition of done. Real <label for> on every control · help and error text wired via aria-describedby · aria-invalid on the failed control · error color never the only signal (the message text is) · border ≥3:1 in both states.
