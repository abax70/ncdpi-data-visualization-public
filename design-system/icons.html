Design system — icons & Tableau kit

On-brand icons, packaged for Tableau dashboards

A ready-made folder of icons for Tableau dashboards. The icons come from Bootstrap Icons, the open-source family the NCDPI Web Style Guide names for agency websites, so a dashboard and the website it links from look like they belong together. Everything is single-color on a transparent background, in the sizes and formats Tableau expects.

⬇ Download the NCDPI Tableau Kit (.zip)

What’s in the kit

Folder Use it for
Shapes/NCDPI Icons - Black Mark shapes you want Tableau to color: put a field on Color and the icons take its colors.
Shapes/NCDPI Icons - Navy Mark shapes that should stay NCDPI navy (#003A70).
Shapes/NCDPI Icons - White Mark shapes on a navy or dark background. They look blank in Tableau's white shape picker; that's expected.
Dashboard Images/Icons - Navy, - White Icons placed with an Image object: buttons, headers, navigation.

Need the NCDPI logo? It isn’t in the kit. The graphics team provides official Tableau-ready logo files — ask graphics@dpi.nc.gov, and see the logo page for which version to use where.

Why some files end in @2x. Tableau Desktop treats an image named name@2x.png as a high-resolution version and draws it at half its pixel size, so it stays sharp on high-resolution screens. That applies to dashboard images, so those files carry the suffix — keep it when you use them. Tableau doesn’t document the convention for shapes, so shape files don’t have it.

Install

Shapes (one time):

  1. In File Explorer, open Documents\My Tableau Repository\Shapes.
  2. Copy the three NCDPI Icons folders from the kit’s Shapes folder into it.
  3. In Tableau, open Shape on the Marks card (click Reload Shapes if Tableau was already open). Each folder appears as a palette under its own name.

Custom shapes are saved inside the workbook, so colleagues who open your workbook don’t need the kit installed.

Dashboard images: keep the Dashboard Images folder somewhere permanent (not Downloads), then drag an Image object onto your dashboard and pick a file.

How to use icons

These rules come from the NCDPI Web Style Guide’s iconography page and apply to dashboards as much as to web pages.

  • Icons help people navigate or act — they aren’t decoration. If removing an icon loses nothing, leave it out.
  • One color per icon, in one of the two approved pairs:
White on navy
Navy on pale blue
  • One icon family per dashboard. Don’t mix these with icons from another set.
  • An icon-only button needs words. Give it a text label or a tooltip that says what it does (“Download data”, not “Download icon”). People who can’t make out the symbol still need to know what it does.

The icons

Each file is named for what it means, with a prefix that keeps related icons together in Tableau’s shape picker (ui-, help-, data-, edu-, people-, place-). Need one that isn’t here? The full Bootstrap Icons set has about 2,000 at https://icons.getbootstrap.com — ask us to add it to the kit rather than mixing in another family.

On web pages

Web projects should use the icons as SVG — the same files this page shows, from https://icons.getbootstrap.com. Inline the SVG and leave its fill="currentColor" alone, so the icon takes the text color of whatever it sits in. Mark a decorative icon aria-hidden="true"; an icon that is the only content of a link or button needs an accessible name on that link or button.
