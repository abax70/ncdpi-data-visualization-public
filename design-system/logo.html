Design system — logo

How to use the NCDPI logo in the things this system builds — pages, dashboards, and apps. The canonical sources are the graphics team’s: the DPI Logo Kit (assets + Logo Kit Guidelines.pdf) and the DPI Style Guide. This page is the usage layer — which file, on what background, at what size — plus the web-specific rules (alt text, linking) the print guidance doesn’t cover. Need a format the kit doesn’t ship? Ask the graphics team at graphics@dpi.nc.gov — don’t build one.

Which file do I use?

Context Use File
Web page or app, light background Horizontal, blue NCDPI-Horizontal-Blue.svg
Navy or dark band (header, footer) Horizontal, white NCDPI-Horizontal-White.svg
Tableau dashboard Tableau-ready PNG (@2x) Tableau Ready Logos/ — blue, white, dark-navy, white-on-blue
Square slot — partner-logo grids, app icons Centered version, or the square icon (sparingly) Centered Version/ · NCDPI Icon-web-apps-small/
Print, vendors, media Vector from the kit .eps / .pdf (Pantone, fonts outlined)

The preference order comes straight from the Logo Kit Guidelines: the horizontal version for most applications, blue as the first choice; white on dark backgrounds; the four-color seal version only where little other color competes (a splash page, not a dashboard); the centered and icon versions only when the slot truly demands them.

On our surfaces

The two SVGs above ship with this site (assets/ncdpi-logo-blue.svg, assets/ncdpi-logo-white.svg) and are byte-identical to the kit’s svgs/ folder — copy them into a consuming project as they are. On the navy header band, the white version is the only correct pick: the blue logo disappears against surface-brand, and no token pairing will rescue it.

In the header component, the logo drops into the brand slot:

<header class="ncdpi-header">
  <span class="ncdpi-header__brand">
    <img src="assets/ncdpi-logo-white.svg" alt="NC Department of Public Instruction"
         style="height:32px; width:auto;">
  </span>
  <span class="ncdpi-header__tagline">Educator Preparation Data</span>
</header>

Placement and size (web)

From the NCDPI Web Style Guide:

  • Upper-left corner, linked to the site’s home page. Readers expect it; screen-reader users depend on it.
  • Desktop: a 250 × 75 px slot. The horizontal mark is wider than it is tall (279 : 57.6 ≈ 4.8 : 1), so at 250 px wide it stands about 52 px — it fits the slot; don’t stretch it to fill.
  • Mobile: max-width 225 px, scaled proportionally.

Scale by width or height, never both. Use the files as shipped: no recoloring, no stretching, no shadows or outlines. If a treatment the kit doesn’t ship seems necessary, that’s a question for the graphics team, not a local edit.

Accessibility

  • The logo <img> always carries alt text: “NC Department of Public Instruction.” Not “logo” — the image is the name.
  • When the logo is a link (the usual case), the accessible name should say where it goes: alt="NC Department of Public Instruction — home" or an aria-label on the link. A screen-reader user tabbing the header hears the destination, not a description of artwork.
  • Prefer the SVGs on the web — they stay crisp at every zoom level, which matters for WCAG’s 400 % reflow, and they’re smaller than the PNGs.
  • The white-on-navy pairing is the token grid’s validated on-surface-brand on surface-brand; the logo inherits that headroom.

The logo’s colors — and a known quirk

The Logo Kit Guidelines give the agency logo palette (these are the logo’s colors, not the dataviz palettes — never paint charts with them):

Color Pantone Stated hex
Blue 648 #002D5D
Purple (seal, 4c) 242 #541043
Green (seal, 4c) 583 #A9C040
NoteThe kit’s blues don’t all match — use the file, don’t retype the hex

Measured, the kit’s assets carry three slightly different blues by lineage: the guidelines state Pantone 648 = #002D5D; the print-derived PNGs paint ≈ #14315A (a CMYK conversion of the same ink); and the kit’s SVGs paint #003A70 — the same navy as the dataviz system. All read as “NCDPI blue” at a glance. The practical rule: place the shipped file and leave its colors alone. If you’re matching a background to the logo exactly (as NCDPI-Horizontal-WhiteOnBlue does — its field is #003A70), sample the asset you’re actually using rather than trusting a remembered hex.

A related note from the guidelines: the agency typeface in the logo is Univers (Arial and Helvetica are the sanctioned stand-ins for documents), but the kit’s vectors ship with fonts converted to outlines — you never need the font installed to use the logo files.

Where the assets live

In this repo: branding/DPI Logo Kit/ (the full kit — vector, raster, Tableau-ready, icons, and the guidelines PDF) and branding/DPI Style Guide-2025.pdf. The two web SVGs are mirrored at site/assets/. The kit is for vendors, media, and agency partners by design — if someone outside DPI asks for the logo, point them to graphics@dpi.nc.gov rather than forwarding files.
